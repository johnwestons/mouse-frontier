ACTION MENUS AND DEBUG ACTIVITIES

Player access
- Open player options (F2, or Pause / Options / Touch Controls).
- Controls selects Radial Wheel, Quick Dock, or Button Drawer.
- Advanced UI Editor > Menus selects a base and previews Closed, Main, Poses, or More.
- Tap an individual control to move it. Layout, Color and Art edit size, rotation, tint, text and icon size. Undo/redo and the three saved GUI presets include the chosen base layout.
- Ring slices retain their authored artwork; button and panel frames support the existing alternate frames.
- Controls retain separate edits for each base layout and game scene.
- Menu actions activate on release. Sliding off a control cancels it. A second finger cannot double-activate an action. Close, an outside tap, Escape or controller B dismisses a menu.

Art
- The active simple sprite set is in assets/sprites/ui/actions/simple: flat brown panels, thin amber outlines, cream icons, and a circular close control.
- All three base layouts share the simple sprites and retain individual control editing. The earlier decorative art is retained in assets/sprites/ui/actions.
- Character symbols are mice; Use is a paw. No human icons are used in these layouts.
- Original image files are retained; atlas source rectangles trim padding without editing the generated pixels.
- Generation prompts and selected source filenames are in assets/sprites/ui/actions/simple/generation-prompts.json.

Cheats > Play Minigames
- Available inside a loaded offline save. Disconnect Local Play before using it.
- Gun Range, Bandit Attack, Last Stand backyard, Last Stand shootout, First Aid Practice, Maintenance, Sewing, Weapon Repair, Tactical Battle, and all four adventure areas are listed.
- The launcher changes the current save's location and starts the selected activity. Ordinary activity costs/rewards and exits still apply.
- Test Supplies is on by default and can be switched off. It restores health, supplies and ammunition, adds a test firearm where needed, and supplies the first sewing recipe. It requires free inventory slots and never replaces existing items.
- Weapon Repair selects a worn rifle when test supplies are enabled. First Aid Practice has no quest reward. Adventure progress and completed character conversations are retained.
- Launching another activity replaces the current active encounter. Last Stand and Bandit Attack can be replayed.
