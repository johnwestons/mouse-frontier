# Courier Prime

The game uses the unmodified Courier Prime Regular and Bold TrueType fonts,
designed by Alan Dague-Greene for John August and released by Quote-Unquote Apps.

Source: https://github.com/google/fonts/tree/main/ofl/courierprime
Upstream: https://github.com/quoteunquoteapps/CourierPrime
Downloaded: 2026-09-11

1.1 in `OFL.txt`. The mobile packager includes both `.ttf` files and that license.
